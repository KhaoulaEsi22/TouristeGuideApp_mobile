# Tourist Guide App

C2C Personal Project
Application for communication between guides and tourists in morocco
### We will use
- Java 17
- Maven
- PostgreSQL (ou autre DB configurée)

### Steps

Backend run:
mvn clean install
mvn spring-boot:run

Frontend run with react native:
npm install
npx expo start -c
